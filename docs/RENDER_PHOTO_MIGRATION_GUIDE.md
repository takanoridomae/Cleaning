# Render既存写真のNAS移行ガイド

## 📋 概要

Render Persistent Diskに保存されている既存の写真を、NASに移行するための手順書です。

## 🎯 移行の目的

- **ローカルLAN運用への移行**: Renderクラウド運用からローカルネットワーク運用に切り替え
- **写真の一元管理**: 過去のRender保存写真もNASで管理
- **バックアップ保持**: 移行後もRender上の写真は削除せず、バックアップとして保持

## ⚠️ 重要な前提条件

### 必須要件

1. **NAS環境が構築済みであること**
   - UGREEN NASが稼働中
   - WebDAVサービスが有効（ポート5005）
   - 保存先フォルダ `/home/eacon_keep_pict` が存在

2. **Render環境変数が設定済みであること**
   ```
   NAS_ENABLED=True
   NAS_WEBDAV_URL=http://100.69.218.15:5005
   NAS_USERNAME=Takanori
   NAS_PASSWORD=（パスワード）
   NAS_BASE_PATH=/home/eacon_keep_pict
   ```

3. **ネットワーク接続**
   - **方法A**: RenderサーバーにTailscaleがインストールされている
   - **方法B**: NASがパブリックIPでアクセス可能（非推奨）
   
   ⚠️ **注意**: 通常、Render環境からTailscale VPNにアクセスすることは困難です。
   そのため、この移行方法が使えない場合は「代替方法」を参照してください。

## 🚀 移行手順（Render Shell使用）

### ステップ1: 環境変数の確認

1. **Renderダッシュボードにログイン**
   - https://dashboard.render.com/

2. **Webサービスを選択**
   - エアコン報告書システムのサービスを選択

3. **環境変数の確認**
   - 左メニュー「Environment」をクリック
   - 以下の環境変数が設定されていることを確認:
     - `NAS_ENABLED` = `True`
     - `NAS_WEBDAV_URL` = `http://100.69.218.15:5005` (または適切なURL)
     - `NAS_USERNAME` = `Takanori`
     - `NAS_PASSWORD` = (パスワード)
     - `NAS_BASE_PATH` = `/home/eacon_keep_pict`

4. **環境変数を追加/変更した場合**
   - 「Save Changes」をクリック
   - サービスの再デプロイを待つ（2-5分）

### ステップ2: Render Shellに接続

1. **Shellタブを開く**
   - Renderダッシュボード > 対象サービス > 上部メニュー「Shell」

2. **Shell接続を待つ**
   - 接続完了まで数秒～数十秒待機
   - プロンプト（`$ `）が表示されれば接続成功

3. **現在のディレクトリを確認**
   ```bash
   pwd
   ```
   出力例: `/opt/render/project/src`

### ステップ3: 移行前の確認

1. **写真の存在確認**
   ```bash
   ls -lh uploads/before/ | head -10
   ls -lh uploads/after/ | head -10
   ```

2. **写真の件数確認**
   ```bash
   # 画像ファイル（.jpg, .jpeg, .png, .gif）の件数を確認
   echo "施工前写真: $(find uploads/before/ -maxdepth 1 -type f \( -iname "*.jpg" -o -iname "*.jpeg" -o -iname "*.png" -o -iname "*.gif" \) | wc -l)件"
   echo "施工後写真: $(find uploads/after/ -maxdepth 1 -type f \( -iname "*.jpg" -o -iname "*.jpeg" -o -iname "*.png" -o -iname "*.gif" \) | wc -l)件"
   ```
   
   ⚠️ **注意**: `uploads/before/`や`uploads/after/`内にサブディレクトリが存在する場合がありますが、
   移行スクリプトは**ファイルのみ**を対象とし、ディレクトリは自動的に除外されます。

## 🔧 トラブルシューティング

### エラー1: NASに接続できません

**エラーメッセージ:**
```
❌ NASに接続できません

考えられる原因:
  1. NAS_ENABLED が True に設定されていない
  2. 環境変数が正しく設定されていない
  3. Render環境からTailscaleネットワークにアクセスできない
  4. NAS WebDAVサービスが起動していない
```

**対処法:**

1. **環境変数を確認**
   ```bash
   echo $NAS_ENABLED
   echo $NAS_WEBDAV_URL
   echo $NAS_USERNAME
   ```

2. **NAS WebDAVサービスの確認**
   - NAS管理画面でWebDAVサービスが起動中か確認

3. **ネットワーク接続の確認**
   - Render ShellからNASにpingを試行（通常は失敗する）
   ```bash
   ping -c 3 100.69.218.15
   ```
   
   ⚠️ **Render環境からTailscale IPにアクセスできない場合が多いです**
   
   この場合は、**代替方法（ローカルPC経由）** を使用してください。

### エラー2: 認証エラー

**エラーメッセージ:**
```
WebDAVアップロードエラー: 401 Unauthorized
```

**対処法:**
1. `NAS_USERNAME` と `NAS_PASSWORD` が正しいか確認
2. NASのユーザー権限を確認
3. WebDAV認証設定を確認

### エラー3: ディスクフルエラー

**エラーメッセージ:**
```
NASアップロードエラー: 507 Insufficient Storage
```

**対処法:**
1. NASの空き容量を確認
2. 不要なファイルを削除して容量を確保

## 💡 代替方法: ローカルPC経由での移行

Render環境からNASに直接アクセスできない場合は、以下の手順で移行できます。

### 方法A: Render Shell経由でダウンロード

1. **Render Shellで写真をアーカイブ化**
   ```bash
   # アーカイブ作成
   cd /opt/render/project/src
   tar -czf photos_backup.tar.gz uploads/before uploads/after
   
   # サイズ確認
   ls -lh photos_backup.tar.gz
   ```

2. **アーカイブをダウンロード可能な場所に配置**
   
   ⚠️ **注意**: Render Shellから直接ファイルをダウンロードすることは困難です。
   
   代わりに、以下の方法を使用してください:

### 方法B: Renderアプリケーション経由（推奨）

1. **一時的なダウンロードエンドポイントを作成**（管理者のみ）
   
   または

2. **データベース経由で写真一覧を取得**
   ```bash
   # Render Shell上で実行
   python scripts/utilities/export_photo_list.py
   ```

3. **ローカルPCでダウンロードスクリプトを実行**
   - 写真一覧を元に、各写真をダウンロード
   - ダウンロード後、ローカル環境の移行スクリプトを実行

### 方法C: データベースエクスポート経由

この方法は別途スクリプト作成が必要です。詳細は開発担当者にお問い合わせください。

## 📞 サポート

### よくある質問

**Q: 移行後、Render上の写真は削除されますか？**
A: いいえ、削除されません。バックアップとして保持されます。

**Q: 移行中にエラーが発生したらどうなりますか？**
A: エラーが発生した写真はスキップされ、他の写真の移行は継続されます。

**Q: 既にNASに存在する写真はどうなりますか？**
A: 重複アップロードを避けるため、自動的にスキップされます。

**Q: 移行を途中で中断してもよいですか？**
A: はい。中断しても問題ありません。再実行時は既に移行済みの写真はスキップされます。

### 問題が解決しない場合

1. エラーメッセージをコピーして保存
2. 以下の情報を確認:
   - NAS接続状態
   - 環境変数設定
   - ネットワーク接続
3. 開発担当者に連絡
